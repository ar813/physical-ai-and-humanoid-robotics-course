# Physical AI & Humanoid Robotics Course

**Learn to build intelligent robots from basics to advanced AI integration.**

Welcome to the official repository for the **Physical AI & Humanoid Robotics** course by **Panaversity**. This comprehensive curriculum is designed to take you from the fundamentals of robotics to cutting-edge applications in humanoid movement, vision, and interaction.

## 📚 About the Course

This course bridges the gap between physical hardware and artificial intelligence. Students will explore:
- **ROS 2** (Robot Operating System) for robot control and communication.
- **Robot Physics & Simulation** using NVIDIA Isaac and other tools.
- **Vision & Mapping** techniques for environmental perception.
- **Humanoid Robotics** specifically focusing on walking balance, manipulation, and interaction.
- **Generative AI** integration for "talking" robots and advanced decision making.

## 🎓 Course Curriculum

The course is structured into 18 detailed modules:

- **Module 01: Introduction** - Course overview and setup.
- **Module 02: Intelligent Machines** - Understanding AI in the physical world.
- **Module 03: Robot Sensing** - Sensors, perception, and data acquisition.
- **Module 04: ROS 2 Basics** - Core concepts of the Robot Operating System.
- **Module 05: ROS 2 Programming** - Writing nodes, topics, and services.
- **Module 06: Simulation** - Simulating robots in virtual environments.
- **Module 07: Robot Models** - URDF, kinematics, and dynamics.
- **Module 08: Robot Physics** - Physics engines and realistic interactions.
- **Module 09: NVIDIA Isaac** - Advanced simulation with Isaac Sim/Gym.
- **Module 10: Vision & Mapping** - SLAM, object detection, and depth sensing.
- **Module 11: Humanoid Movement** - Kinematics for humanoid robots.
- **Module 12: Walking & Balance** - Gait generation and stability control.
- **Module 13: Manipulation & Interaction** - Grasping and object handling.
- **Module 14: VLA (Vision-Language-Action)** - Multimodal models for robotics.
- **Module 15: Talking Robots** - Integrating LLMs for natural interaction.
- **Module 16: Hardware** - Real-world hardware components and assembly.
- **Module 17: Sim-to-Real** - Transferring policies from simulation to reality.
- **Module 18: Final Project** - Capstone project implementation.

## 🚀 Getting Started

This documentation site is built using Docusaurus. Follow these steps to run it locally.

### Prerequisites

- [Node.js](https://nodejs.org/en/) (version 18.0 or above)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/panaversity/physical-ai-and-humanoid-robotics-course.git
   cd physical-ai-and-humanoid-robotics-course
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

### Running Locally

Start the development server:
```bash
npm start
```
This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

### Building for Production

Generate static content into the `build` directory:
```bash
npm run build
```
